# Choisir une couleur au hasard

Outil gratuit en français : https://generateurdecouleur.com/choisir-une-couleur-au-hasard/

Il choisit une couleur nommée, pas un code HEX. Utile quand on veut juste qu'on dise « bleu » ou « rouge » : jeu, classe, décision rapide.

## Couleurs possibles

Rouge, bleu, vert, jaune, orange, violet, rose, noir, blanc, gris, marron.

## Utilisation

1. Ouvrir la page.
2. Cliquer sur « Choisir une couleur » ou appuyer sur Espace.
3. Lire le nom affiché. Recommencer pour une autre couleur.

## Ce que cet outil n'est pas

Ce n'est pas un générateur de code HEX / RGB / HSL. Pour une couleur précise à copier dans du CSS ou un outil de design, utiliser [le générateur de couleur aléatoire](https://generateurdecouleur.com/index.md).

Pour piocher dans votre propre liste (classe, jeu, équipes), utiliser [le tirage au sort de couleur](https://generateurdecouleur.com/tirage-au-sort-couleur.md).
