# Générateur de couleur aléatoire

Outil gratuit en français : https://generateurdecouleur.com

Il choisit une couleur au hasard parmi 16 777 216 couleurs HEX et affiche les codes HEX, RGB et HSL, chacun copiable.

## Utilisation

1. Ouvrir la page. Une couleur s'affiche tout de suite en fond.
2. Copier le format dont vous avez besoin : HEX, RGB ou HSL.
3. Cliquer sur « Générer une autre couleur » ou appuyer sur Espace pour en obtenir une nouvelle.

## Ce que cet outil n'est pas

Ce n'est pas un tirage de couleurs nommées (rouge, bleu, vert…). Pour ça, utiliser [Choisir une couleur au hasard](https://generateurdecouleur.com/outils/choisir-une-couleur-au-hasard.md).

Pour plusieurs couleurs d'un coup, utiliser [le générateur de palette](https://generateurdecouleur.com/outils/palette-couleurs.md). Pour passer d'un format à l'autre, utiliser [le convertisseur](https://generateurdecouleur.com/outils/convertisseur-couleur.md).
