# Tirage au sort de couleur

Outil gratuit en français : https://generateurdecouleur.com/outils/tirage-au-sort-couleur

Il pioche une couleur dans une liste fournie par l'utilisateur. Utile pour la classe, un jeu, un atelier, ou comme dé virtuel de couleur.

## Utilisation

1. Écrire une couleur par ligne.
2. Cliquer sur « Tirer une couleur ».
3. Optionnel : retirer la couleur tirée pour qu'elle ne ressorte plus.
4. Réinitialiser la liste pour recommencer.

La liste est enregistrée localement dans le navigateur.

## Ce que cet outil n'est pas

Il pioche seulement dans la liste écrite sur la page. Il ne fournit pas de code couleur.

- Couleur simple déjà prête : [choisir une couleur au hasard](https://generateurdecouleur.com/outils/choisir-une-couleur-au-hasard.md)
- Code à copier : [générateur de couleur aléatoire](https://generateurdecouleur.com/index.md)
