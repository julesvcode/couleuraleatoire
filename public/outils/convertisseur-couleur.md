# Convertisseur de couleur HEX, RGB, HSL et CMYK

Outil gratuit en français : https://generateurdecouleur.com/outils/convertisseur-couleur/

Il convertit une couleur entre HEX, RGB, HSL et CMYK. Modifier un format met les autres à jour. Chaque valeur est copiable.

## Utilisation

1. Coller un code HEX, RGB, HSL ou CMYK, ou choisir une couleur.
2. Lire les autres formats, mis à jour automatiquement.
3. Copier le format dont vous avez besoin.

## Ce que cet outil n'est pas

- Pas un générateur de couleur au hasard : [générateur de couleur aléatoire](https://generateurdecouleur.com/index.md)
- Pas un générateur de palette : [générateur de palette de couleurs](https://generateurdecouleur.com/outils/palette-couleurs.md)

Il n'existe pas de pages séparées du type HEX vers RGB : tout se fait ici.
