# Générateur de palette de couleurs

Outil gratuit en français : https://generateurdecouleur.com/outils/palette-couleurs

Il génère une palette de 5 couleurs. Chaque couleur peut être verrouillée pour rester en place quand on génère le reste. Toute la palette peut s'afficher et se copier en HEX, RGB, HSL ou CMYK.

## Utilisation

1. Ouvrir la page. Cinq couleurs s'affichent.
2. Verrouiller celles à garder.
3. Choisir le format : HEX, RGB, HSL ou CMYK.
4. Cliquer sur « Générer une nouvelle palette » ou appuyer sur Espace.
5. Copier une couleur, ou toutes d'un coup, dans le format choisi.

## Ce que cet outil n'est pas

- Pas un générateur d'une seule couleur : [générateur de couleur aléatoire](https://generateurdecouleur.com/index.md)
- Pas un convertisseur d'une seule couleur avec tous les formats à la fois : [convertisseur de couleur](https://generateurdecouleur.com/outils/convertisseur-couleur.md)
